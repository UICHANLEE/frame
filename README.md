# 영뽀또 감성 구도 카메라 클론

App Store의 `영뽀또 - 감성 구도 카메라` 설명을 기준으로 만든 모바일 우선 웹 카메라 앱입니다.

원본 앱의 유료 콘텐츠, 브랜드 자산, 실제 필터 LUT, 강의 본문을 복제하지 않고, 공개 설명에서 확인되는 핵심 사용 흐름을 웹에서 동작하도록 재구성했습니다.

## 구현 기능

- 모바일 풀스크린 카메라 UI
- iOS/Android 브라우저용 `playsinline`, `capture`, safe-area 대응
- 전면/후면 카메라 전환
- 사진 불러오기 및 카메라 촬영
- 실시간 구도 가이드
  - 삼분할
  - 중앙
  - 수평선
  - 대각선
  - 인물 여백
  - 황금나선
- 감성 필터
  - 영뽀또
  - 동화
  - 데일리
  - 시네마
  - 노을
  - 모노
- 필터 세기, 필름 그레인, 비네팅 조절
- 촬영 팁 카드
- PNG 저장
- PWA manifest 추가

## 실행

```bash
python3 -m http.server 8899 --bind 127.0.0.1
```

로컬에서 확인:

```text
http://127.0.0.1:8899
```

## 모바일 카메라 주의사항

모바일 브라우저에서 `getUserMedia` 카메라는 보안 컨텍스트가 필요합니다. `localhost` 또는 `https`에서는 동작하지만, 같은 와이파이의 `http://내IP:포트` 접속은 카메라 권한이 막힐 수 있습니다. 실제 폰 테스트는 GitHub Pages, Vercel, Netlify 같은 HTTPS 배포 주소에서 확인하는 방식이 안정적입니다.
