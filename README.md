# 영뽀또 감성 구도 카메라 클론

App Store의 `영뽀또 - 감성 구도 카메라` 설명을 기준으로 만든 웹 클론입니다.

원본 앱은 네컷 사진 앱이 아니라, 촬영 중 구도 가이드라인과 감성 필터를 보면서 사진/영상을 찍는 카메라 앱입니다. 이 구현은 웹 브라우저에서 동작 가능한 범위로 핵심 기능을 재구성했습니다.

## 구현 기능

- 웹캠 기반 실시간 카메라
- 사진 파일 불러오기
- 샘플 장면으로 즉시 테스트
- 구도 가이드라인: 삼분할, 중앙, 수평선, 대각선, 인물 여백
- 감성 필터: 맑은 필름, 동화, 시네마, 노을, 모노
- 이펙트: 그레인, 비네팅
- 촬영 팁/구도 강의 카드
- PNG 저장

## 실행

```bash
python3 -m http.server 8899 --bind 127.0.0.1
```

브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8899
```

카메라 기능은 브라우저 권한 허용이 필요합니다.

## 참고

이 프로젝트는 학습용 기능 클론입니다. 원본 앱의 브랜드 자산, 유료 콘텐츠, 실제 필터 LUT, 강의 콘텐츠, 내부 UX를 복제하지 않았습니다.
